# สถิติเลขท้าย 2 ตัว

หน้าเว็บสถิติเลขท้าย 2 ตัว (2 ตัวล่าง) ย้อนหลัง 3 ปี ที่อัปเดตตัวเองหลังออกรางวัลทุกงวด

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บ อ่านข้อมูลจาก `data/draws.csv` แล้วคำนวณทุกอย่างเอง |
| `data/draws.csv` | ผลรางวัลทุกงวด (`date` เป็น ค.ศ., `last2` เป็นเลข 2 หลัก) |
| `scripts/update_draws.py` | ดึงผลงวดล่าสุดจากกองสลาก แล้วเพิ่มลงใน CSV |
| `.github/workflows/update.yml` | สั่งให้ GitHub รันสคริปต์ทุกวัน และ deploy หน้าเว็บเมื่อมีงวดใหม่ |

หน้าเว็บนับเฉพาะงวดภายใน 3 ปีจากงวดล่าสุด พองวดใหม่เข้ามา งวดเก่าสุดจะหลุดออกไปเอง
ตัวเลขทุกจุดในหน้า (จำนวนงวด, ปีในตาราง, เลขที่ออกบ่อย, ช่องแดงงวดล่าสุด) คำนวณใหม่ทุกครั้งที่เปิด

## ตั้งค่าครั้งแรก

1. สร้าง repository ใหม่บน GitHub เช่น `lotto-stats` (เลือก Public ถ้าใช้บัญชีฟรี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป ให้โครงสร้างโฟลเดอร์เหมือนเดิม รวมถึงโฟลเดอร์ `.github`
3. ไปที่ **Settings > Pages** ตรง Source เลือก **GitHub Actions**
4. ไปที่ **Settings > Actions > General** ตรง Workflow permissions เลือก **Read and write permissions** แล้วกด Save
5. ไปที่แท็บ **Actions** ตอนอัปโหลดไฟล์ในข้อ 2 GitHub จะลอง deploy ไปแล้วหนึ่งครั้ง ถ้ารายการนั้นขึ้นกากบาทสีแดง (เพราะตอนนั้นยังไม่ได้ตั้งข้อ 3–4) ให้กดเข้าไปแล้วกด **Re-run all jobs**
6. เมื่อขึ้นเครื่องหมายถูกสีเขียว หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/lotto-stats/`
7. ทดสอบการดึงผลอัตโนมัติ: แท็บ Actions > **Update lottery stats** > **Run workflow** (เว้นช่องว่างไว้) แล้วเปิดดู log ในขั้น "Fetch latest draw" ว่าดึงได้หรือไม่

## อัปเดตอัตโนมัติทำงานอย่างไร

- GitHub จะรันสคริปต์ทุกวันเวลา 17:20 และ 20:10 (เวลาไทย) วันออกรางวัลไม่ตายตัว เลยเช็กทุกวัน
- สคริปต์ถาม API ของกองสลาก ถ้าได้งวดที่ใหม่กว่าในไฟล์ จะเพิ่มลง CSV แล้ว commit ให้
- มี commit ใหม่เมื่อไร หน้าเว็บก็ deploy ใหม่ภายในไม่กี่นาที
- ถ้าไม่มีงวดใหม่ จะจบโดยไม่แก้อะไร
- ตารางเวลาของ GitHub อาจช้ากว่าที่ตั้งไว้ได้ 5–30 นาทีในช่วงที่ระบบมีงานเยอะ

## ถ้าอัปเดตอัตโนมัติไม่ทำงาน

API ของกองสลากไม่มีเอกสารทางการ และอาจเปลี่ยนรูปแบบได้ ถ้าเห็นใน log ว่า "ดึงผลอัตโนมัติไม่สำเร็จ" ใส่ผลเองได้ 2 วิธี

**วิธีที่ 1 กดรันพร้อมใส่ผล**
แท็บ Actions > Update lottery stats > Run workflow แล้วกรอก
- `date`: วันที่งวดเป็น ค.ศ. เช่น `2026-10-16`
- `last2`: เลขท้าย 2 ตัว เช่น `57`

**วิธีที่ 2 แก้ไฟล์ตรงๆ**
เปิด `data/draws.csv` บนเว็บ GitHub กดรูปดินสอ เพิ่มบรรทัดท้ายไฟล์ เช่น `2026-10-16,57` แล้ว Commit changes

ทั้งสองวิธีจะ deploy หน้าเว็บใหม่ให้เอง

## ทดสอบบนเครื่องตัวเอง

เปิด `index.html` ด้วยการดับเบิลคลิกตรงๆ จะโหลด CSV ไม่ได้ (เบราว์เซอร์ไม่อนุญาต) ให้รันเซิร์ฟเวอร์เล็กๆ แทน

```bash
cd lotto-stats
python -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ใส่ผลเองผ่านสคริปต์ก็ได้

```bash
python scripts/update_draws.py --date 2026-10-16 --last2 57
```
